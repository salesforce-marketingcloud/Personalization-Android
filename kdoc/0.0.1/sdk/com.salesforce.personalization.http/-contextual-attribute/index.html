ContextualAttribute

@Serializable
data class ContextualAttribute(val value: Any?)

Represents a contextual attribute value that can store specific data types.

Supported types:

  • String: Used as-is

  • Boolean: Stored as boolean

  • Number (Int, Long, Double, Float, Short, Byte): Stored as number

  • Date: Converted to ISO 8601 datetime format with UTC timezone during creation

  • null: Creates attribute with null value

All other types are rejected with IllegalArgumentException.

Date Handling

When a Date object is provided, it is immediately converted to an ISO 8601 string in the format: yyyy-MM-dd'T'HH:mm:ss.SSS'Z' (e.g., "2024-01-15T10:30:45.123Z"). The conversion happens during creation, and the ContextualAttribute stores the resulting string value, not the original Date object.

Type Safety

The constructor validates that only supported types are provided. Unsupported types will throw an IllegalArgumentException with a descriptive error message.

Serialization

This class is designed for serialization-only use. The @Contextual annotation on the value property allows the Kotlin serialization framework to handle the Any? type appropriately.
