PersonalizationReadyListener
Link copied to clipboard
fun interface PersonalizationReadyListener

Returns a valid instance of PersonalizationSdk when it is ready. If initialization of the SDK has already completed then the PersonalizationReadyListener will be notified immediately. If PersonalizationSdk.configure has not been called, or is executing, PersonalizationReadyListener will be called upon completion.

Note: If PersonalizationSdk.configure completes with a status of InitializationStatus.FAILURE for InitializationStatus.status then then PersonalizationReadyListener will not be called, and the current list of PersonalizationReadyListener listeners will be cleared.
