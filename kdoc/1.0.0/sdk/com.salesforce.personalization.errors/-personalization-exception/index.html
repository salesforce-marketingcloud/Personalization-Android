PersonalizationException

sealed class PersonalizationException : Exception

Base class for all PersonalizationSDK exceptions.

Provides structured exception information with type for classification, reason for specific exception details, and optional cause for exception chaining.

Usage:

when (result) {
    is Result.Failure -> {
        when (result.throwable.type) {
            PersonalizationException.Type.NETWORK -> logNetworkException()
            PersonalizationException.Type.TIMEOUT -> logTimeoutException()
            else -> logException()
        }
    }
}
