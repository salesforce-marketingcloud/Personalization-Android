The complete JSON representation of this content object as a map of JsonElements.

This property provides direct access to the underlying JSON structure, allowing developers to access any field present in the original JSON response. This is particularly useful for:

  • Accessing custom fields that aren't part of the standard content object structure

  • Inspecting the raw JSON structure for debugging purposes

  • Building dynamic content processing logic based on available fields

Important Notes:

  • Values are JsonElement objects, not primitive types

  • Missing keys will not be present in the map (use containsKey() to check existence)

  • Explicit JSON null values are represented as JsonNull objects
