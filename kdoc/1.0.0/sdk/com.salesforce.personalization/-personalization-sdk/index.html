PersonalizationSdk

class PersonalizationSdk : ModuleInterface

Salesforce Personalization SDK for Android.

Provides personalized content and experiences by integrating with Salesforce Data Cloud and Marketing Cloud. The SDK fetches personalization decisions based on user context and configured personalization points.

Key Features:

  • Fetch personalized content decisions

  • Context-aware personalization

  • Auto-populating user information from Data Cloud and the host app

  • Lifecycle-aware coroutine support

  • Type-safe error handling

Usage:

// Configure PersonalizationSdk through SFMCSdk
val personalizationConfig = PersonalizationConfig.Builder(context)
    .dataspace("default")
    .build()

val cdpConfig = CdpConfig.Builder(
    context,
    "your-app-id",
    "your-endpoint.salesforce.com"
).build()

SFMCSdk.configure(context, SFMCSdkModuleConfig.build {
    personalizationModuleConfig = personalizationConfig
    cdpModuleConfig = cdpConfig
}) { status ->
    // PersonalizationSdk is now ready for use
}
