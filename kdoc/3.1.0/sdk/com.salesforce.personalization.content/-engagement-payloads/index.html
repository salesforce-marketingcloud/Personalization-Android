EngagementPayloads

sealed class EngagementPayloads

Engagement payload/fields associated with a personalization, for use by Low Code Component. See PerAction and PerItemAndAction.

Low-Code Components should track engagement via the ComponentContext.trackEngagement convenience functions, which look up the right EngagementPayload and call EngagementPayloads.track for them. Engagement fires for both PRODUCTION and PREVIEW content; MOCK data carries no payloads, so it tracks nothing.

Delivered to ContentZone via ContentZonePersonalization.engagementPayloads. ContentZone provides to Component via validateAndCreateComponentModel and compose.
